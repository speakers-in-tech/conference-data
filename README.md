## Tech Conference Data

This repository attempts to maintain comprehensive, high-quality data about tech conferences, focusing on their policies regarding the engagement of speakers, and in particular, whether or not organizers have indicated a willingness to stand up for the rights of speakers by signing the official [Speaker Engagement Agreement](https://github.com/speakers-in-tech/sea/blob/main/SEA.md).
More background on this initiative is contained in the blog post, [The Dark Side of Speaking at Tech Conferences](https://www.linkedin.com/pulse/dark-side-speaking-tech-conferences-john-de-goes/?trackingId=U6NAMEIvQr2LFDGbv4A4%2Fw%3D%3D). 

## Disclaimer

All information in this repository is provided on a _best-effort_ basis. If an organizer of any tech conference identifies inaccuracies in the data, please submit a pull request to correct the information.

## Data

The conference data is maintained in [conferences.csv](conferences.csv). Each row represents a tech conference with the following fields:

- **Conference Name**: The name of the conference
- **Website**: The official website URL
- **Location**: The city and state/country where the conference is held
- **Date**: The year or date range of the conference
- **Speaker Engagement Agreement Signed**: Whether the organizer has signed the [Speaker Engagement Agreement](https://github.com/speakers-in-tech/sea/blob/main/SEA.md) (Yes/No)
- **Notes**: Additional context or remarks

## Contributing

If you'd like to contribute data about a tech conference, please:

1. Check if the conference is already listed in [conferences.csv](conferences.csv)
2. If not, add a new row with the available information
3. If an organizer refuses to answer questions, add them assuming they are not willing to sign the Speaker Engagement Agreement. They can always correct the information later, if it proves inaccurate.
4. Submit a pull request with your changes
